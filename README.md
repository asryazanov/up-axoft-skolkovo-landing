# UP: Axoft & Skolkovo Landing

Рабочий прототип лендинга программы UP для стартапов и ИТ-вендоров.

## Возможности

- co-branded лендинг Axoft + Фонд «Сколково»;
- треки UP Base и UP Strategic;
- направления и отрасли из подготовленных материалов;
- форма заявки с локальной API-заглушкой;
- страница благодарности `/thanks`;
- простая локальная админка `/admin` для редактирования JSON-контента в браузере.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:3000`.

## Проверка

```bash
npm run build
```

## Интеграции

Сейчас Bitrix24, Яндекс.Метрика и Yandex SmartCaptcha оставлены как подготовленные точки подключения. Для запуска понадобятся webhook/API Bitrix24, номер счётчика Метрики и ключи SmartCaptcha.
